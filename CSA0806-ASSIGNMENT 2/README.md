## Project Description

This assignment covers Python control flow, loops, string operations, functions, scope, recursion, memoisation, and algorithm optimisation.

## Tasks

### Task 1 – Electricity Subsidy Eligibility

Implement decision-making statements using if, if-else, and if-elif-else to determine subsidy eligibility.

### Task 2 – OTP Verification

Implement OTP verification using while loops, for loops, break, continue, pass, and loop-else.

### Task 3 – Vehicle Registration Validator

Use Python string operations to normalise, validate, and format vehicle registration numbers.

### Task 4 – Monthly SMS Bill Statement

Compare string concatenation using += with string building using join() and measure execution times.

### Task 5 – Functions, Parameters and Scope

Demonstrate function parameters, return values, variable scope, and the mutable default argument problem.

### Task 6 – Recursion and Memoisation

Calculate the number of ways to climb temple steps using recursion and memoisation, and compare the results.

### Task 7 – Diagnose, Redesign and Validate

Identify a limitation in an original program, redesign the solution, and compare performance using measurements.
